# Matplotlib-Seaborn-y-Streamlit

Elige 5 gráficos (charts) e implementa un cuaderno que muestre esos 5 gráficos con Matplotlib y esos mismos en el mismo cuaderno con Seaborn.

Luego implementa una página con StreamLit y visualiza esos 5 gráficos con esa tecnología.


enlace de Streamlit: https://matplotlibseaborn.streamlit.app/


## Conclusión

Realizar los mismos cinco gráficos sobre los influencers de Instagram con estas tres herramientas me ha servido para entender en la práctica para qué sirve realmente cada una y cómo se complementan:   
### Matplotlib (La base clásica y manual): 
Es como dibujar sobre un lienzo en blanco. Te da libertad total para decidir cada pequeño detalle (el color exacto de un borde, el grosor de una línea o la cuadrícula de fondo), pero a cambio exige escribir bastante código para que el gráfico quede visualmente atractivo. Es ideal cuando quieres construir algo muy específico desde cero.   
### Seaborn (El diseño rápido e inteligente): 
Funciona como una capa de mejora sobre Matplotlib. Con muchas menos líneas de código consigue gráficos con un acabado mucho más moderno, limpio y colorido desde el primer momento. Además, aporta detalles visuales muy útiles sin esfuerzo extra, como añadir la curva suave sobre el histograma de seguidores o dibujar automáticamente la línea de tendencia en el gráfico de publicaciones frente a puntuación.   
### Streamlit (El salto a una página web real): 
Mientras que Matplotlib y Seaborn crean imágenes fijas pensadas para quedarse dentro del cuaderno de trabajo, Streamlit convierte todo ese análisis en una aplicación web interactiva. Su gran ventaja es que permite presentar y comparar los gráficos en columnas, organizar la pantalla y compartir el trabajo mediante un simple enlace de internet, sin necesidad de saber programar páginas web.   En definitiva, Matplotlib pone los cimientos y el control de los detalles, Seaborn aporta la estética y la rapidez para analizar los datos, y Streamlit es el escaparate perfecto para que cualquier persona pueda explorar esos resultados de forma visual e interactiva.
